# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | yes       |
| < 1.0   | no        |

Security fixes are released as patch versions of the latest minor release.

## Reporting a vulnerability

Email **security@polyzon.org** with a description of the issue, the affected
version, and steps to reproduce. We acknowledge reports within three working
days and keep you informed until the fix is released. Please give us a
reasonable time to fix the issue before disclosing it.

Do **not** open a public GitHub issue, pull request or discussion for a
vulnerability, and never post API tokens (`pzk_…`), proxy credentials, request
logs containing them, or personal data anywhere public. If a token has leaked,
revoke it at https://polyzon.org/account/ (section «API») first.

Issues with the Polyzon API service itself (api.polyzon.org) go to the same
address.
